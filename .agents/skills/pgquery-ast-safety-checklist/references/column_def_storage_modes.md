# ColumnDef Storage Modes & Generated Columns in pg_query_go

Panduan teknis inspeksi AST PostgreSQL untuk definisi kolom, TOAST storage modes, dan generated columns (khususnya untuk aturan ARGUS-A32 dan seterusnya).

---

## 1. ColumnDef Storage Strategy (TOAST Modes)

PostgreSQL memiliki 4 strategi penyimpanan atribut kolom (TOAST):
- **`PLAIN` (`'p'`):** Tidak dikompresi dan tidak dipindahkan ke tabel TOAST out-of-line (fixed size).
- **`EXTERNAL` (`'e'`):** Diizinkan out-of-line TOAST tanpa kompresi (menghemat CPU decompression).
- **`EXTENDED` (`'x'`):** Default untuk tipe data variabel panjang; kompresi aktif dan out-of-line aktif.
- **`MAIN` (`'m'`):** Kompresi aktif, tetapi sedapat mungkin disimpan inline di page heap utama.

### Gotcha di AST `pg_query_go`:
Pada node `ColumnDef`:
- `colDef.Storage` sering kali berupa string kosong `""`.
- `colDef.StorageName` memuat string nama strategi dalam huruf kecil murni: `"plain"`, `"external"`, `"extended"`, atau `"main"`.
- Jika DDL tidak menyertakan klausa `STORAGE`, maka `colDef.StorageName == ""` dan `colDef.Storage == ""` (artinya default tipe data berlaku).

### Penanganan `ALTER TABLE ... SET STORAGE`:
Pada statement `ALTER TABLE t ALTER COLUMN col SET STORAGE main`:
- Node: `AlterTableStmt`
- `Cmds`: `AlterTableCmd` dengan `Subtype == pg_query.AlterTableType_AT_SetStorage`
- `Name`: nama kolom target (`"col"`)
- `Def`: node `*pg_query.Node_String` yang memuat nilai string (`sval: "main"`).

## 2. Generated Columns (STORED vs VIRTUAL)

Pada SQL PostgreSQL:
```sql
CREATE TABLE t (
    id int,
    total int GENERATED ALWAYS AS (price * qty) STORED
);
```

### Gotcha di AST `pg_query_go`:
1. **Bukan di `colDef.Generated`:**
   Pada raw AST hasil `pg_query.Parse()`, field `colDef.Generated` sering kali kosong `""`.
2. **Berada di dalam `colDef.Constraints`:**
   Definisi generated column diparse sebagai elemen di dalam slice `colDef.Constraints []*pg_query.Node`.
3. **Ciri-ciri Node Constraint:**
   - `c := node.GetConstraint()`
   - `c.Contype == pg_query.ConstrType_CONSTR_GENERATED` (integer enum value: 5).
   - `c.GeneratedWhen`: `"a"` menandakan `GENERATED ALWAYS`, `"d"` menandakan `GENERATED BY DEFAULT`.
   - `c.RawExpr`: memuat subtree ekspresi SQL perhitungan (misal `price * qty`).
4. **STORED vs VIRTUAL:**
   - Dalam PostgreSQL standar ($\le 17/18$), generated column **wajib `STORED`** (PostgreSQL belum mendukung virtual column di grammar standar; upaya menulis `VIRTUAL` memicu syntax error dari libpg_query).
   - Dengan demikian, jika `c.Contype == CONSTR_GENERATED`, kolom tersebut dijamin berstatus `STORED`.
